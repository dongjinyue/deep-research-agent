# Research Evaluation Cases

本文件定义 Deep Research Agent MVP 的初始研究测试集。每个 Case 只规定问题与最低验收要求，不预设最终结论。

## Case 001｜多条件技术比较

### Question

Vue 和 React 哪个更适合大型 SaaS？

### Expected

- 必须考虑性能、生态、招聘和维护成本。
- 必须说明结论适用的团队能力和项目条件。
- 不允许脱离具体约束宣称某个框架绝对更好。
- 关键事实和最终建议必须引用 Sources。

## Case 002｜时效性研究

### Question

截至 2026 年，AI Coding Agent 有哪些主要技术路线？

### Expected

- 必须检索当前资料，不能只依赖模型内部知识。
- 必须区分 IDE Agent、CLI Agent、Cloud Agent 和通用 Software Engineering Agent。
- 必须讨论代码库上下文、工具调用、Sandbox、Agent Loop 和 Human-in-the-loop。
- 对“当前”“最新”“主流”等判断必须给出来源日期。
- 关键事实必须引用 Sources；过期资料必须明确标注时间。

## Case 003｜业务决策研究

### Question

一家约 50 人的跨境电商公司应该自建基于 RAG 的 AI 客服，还是购买成熟的 AI 客服 SaaS？

### Expected

- 必须比较初始投入与持续运营成本。
- 必须考虑数据隐私、安全、集成难度和人工接管机制。
- 必须考虑回答质量、可控性、供应商锁定和扩展能力。
- 必须给出条件化建议，而不是无条件选择一方。
- 关键事实和最终建议必须引用 Sources。
